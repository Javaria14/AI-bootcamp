# Lab 5 - Pandas Data Analysis

## DataFrames and Data Manipulation

This lab focuses on using Pandas for data manipulation, analysis, and handling real-world datasets.

## Topics Covered

- DataFrame Basics
- GroupBy Operations
- Handling Missing Data
- Pandas Concatenation
- Pandas Merge
- Pandas Pivot Tables

## Objective

Develop practical skills in manipulating, combining, and analyzing structured data using Pandas.
