## Lab 10: Outlier Detection using Z-Score & IQR

This lab focuses on identifying and analyzing outliers in datasets using statistical techniques.

### Concepts Covered

- Z-Score for outlier detection
- Interquartile Range (IQR)
- Identifying unusual data points
- Comparing Z-Score and IQR methods
- Data visualization

### Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

### Learning Outcomes

- Understand outliers and their impact on data
- Detect outliers using Z-Score
- Detect outliers using the IQR method
- Visualize and analyze outliers
- Apply statistical methods in data preprocessing
