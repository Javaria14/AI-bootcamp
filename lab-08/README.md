# Lab 8 - Titanic Data Preprocessing & Modeling

## Data Preprocessing and Machine Learning

This lab focuses on preparing the Titanic dataset for machine learning and building a predictive model.

## Topics Covered

- Data Loading and Exploration
- Handling Missing Values
- Data Cleaning
- Feature Selection
- Data Encoding
- Train-Test Split
- Model Training
- Model Evaluation

## Objective

Apply data preprocessing techniques and build a machine learning model to predict passenger survival using the Titanic dataset.
