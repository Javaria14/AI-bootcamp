# Exploratory Data Analysis (EDA) Lab

### Data Exploration & Visualization

This lab focuses on exploring, cleaning, and understanding datasets using Python and common data analysis techniques.

## Topics Covered

- Data Loading & Inspection
- Data Cleaning
- Handling Missing Values
- Descriptive Statistics
- Data Visualization
- Outlier Detection
- Correlation Analysis
- Feature Exploration

## Objective

Develop practical skills in analyzing datasets, identifying patterns and relationships, and gaining meaningful insights through exploratory data analysis.
