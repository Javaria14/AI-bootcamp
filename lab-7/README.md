# Lab 7 - API Development & Testing

## FastAPI, REST API & Flask

This lab focuses on developing and testing APIs using FastAPI and Flask while understanding REST API concepts.

## Topics Covered

- REST API Fundamentals
- FastAPI
- Flask
- API Endpoints
- Request and Response Handling
- API Testing
- Swagger Documentation
- Postman

## Objective

Develop and test basic REST APIs using FastAPI and Flask while gaining practical experience with API development and testing.
